## 🚀 Getting Started

Want to explore or run these programs on your computer? Follow these steps.

**1. Clone the repository**

```bash
git clone https://github.com/Piyu-10/Python---basics--25BCON1553.git
```

**2. Open the project folder**

```bash
cd Python---basics--25BCON1553
```

**3. Check your Python installation**

```bash
python --version
```

**4. Run any program**

For example:

```bash
python calculator.py
```

You can replace `calculator.py` with another Python filename from the repository to run a different program.

*Note: Python must be installed on your system. These programs are intended to use Python's standard library, so additional packages are not expected to be necessary.*
